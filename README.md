## Overview

It's a Cheap Cyber Deck that uses the raspberry pi zero 2 w with a 5inch Display along with a small keyboard this is also a rechargeable cyber deck called Nano Deck

## Features

* Has raspberry pi zero 2 w
* Battery Powered 
* Has a mini Keyboar
* 5inch Display 
* Custom Case
